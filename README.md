# MUA Booking System

Aplikasi sistem informasi pemesanan layanan Make Up Artist (MUA) berbasis web menggunakan framework CodeIgniter 4.

## 🛠️ Tech Stack
- **Framework:** CodeIgniter 4
- **Maps:** Leaflet.js (OpenStreetMap)
- **Database:** MySQL
- **Frontend:** Bootstrap 5

## 📋 Fitur
- Booking layanan (Gallery & Home Service).
- Integrasi Peta Spasial untuk lokasi pelanggan.
- Dashboard Admin untuk manajemen pesanan.

## 🚀 Cara Menjalankan
1. Clone repository ini.
2. Setup database di MySQL.
3. Jalankan `php spark serve`.
